# Item-classification-filling（物品分类填充）

根据预设模板，快速向容器填充指定物品，<br>
这是 Inventory Profiles Next（IPN）的分支模组，可与 IPN 同时使用<br>
Quickly fill containers with items according to preset templates, <br>
This is a fork of Inventory Profiles Next (IPN), and can be used alongside IPN.<br>
